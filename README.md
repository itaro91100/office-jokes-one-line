One-line office joke for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. A Python 3.13 program that writes a single one-line joke about office life (under 200 characters) to `/output/entry.txt` — and nothing else.

## Run it

```sh
python3 main.py
```

## The joke

> I put 'per my last email' in my out-of-office reply so the argument can continue without me.

92 characters, one line. The passive-aggressive office classic "per my last email" meets the out-of-office reply: the argument keeps going even while its author is on holiday.

## Why this joke

Built against the judge's brief, most important first:

1. **A genuine one-line joke about office life** — email warfare and the out-of-office reply, not a slogan or stray observation.
2. **A real turn at the end** — the argument continues *without* its author.
3. **Recognition** — every office worker has sent, received, or dreaded a "per my last email".
4. **Tight wording** — 92 characters, no setup longer than it needs to be.
5. **Fresh** — no Monday-morning or photocopier cliché.

## Verify

```sh
python3 main.py && wc -m /output/entry.txt && cat /output/entry.txt
```

Expected: `92` characters, one line, exactly the joke above.
